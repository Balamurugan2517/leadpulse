LeadPulse AI — Administrator Guide

This guide covers environment setup, Neon PostgreSQL administration, Vercel deployment, background worker management, and security governance.

1. Architecture & Tech Stack

  • Frontend & Server Actions: Next.js 16.4.6 (App Router + Turbopack), React 19.3.1, Tailwind CSS.
  • Database: Neon Serverless PostgreSQL with Drizzle ORM (no S3/object storage required).
  • Monorepo Workspaces: apps/web, apps/worker, packages/domain, packages/contracts, packages/infrastructure, packages/ui.

2. Environment Variables (.env & Vercel)

Configure these variables in root .env locally and in Vercel Project Settings → Environment Variables:

DATABASE_URL="postgresql://user:pass@ep-xxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require"
DATABASE_URL_UNPOOLED="postgresql://user:pass@ep-xxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require"
NEXT_PUBLIC_APP_URL="https://your-deployment.vercel.app"
GOOGLE_PLACES_API_KEY=""   # Optional (free fallback active if omitted)
YOUTUBE_API_KEY=""         # Optional (free fallback active if omitted)

3. Database Schema Management

Push schema updates to Neon PostgreSQL using Drizzle Kit:

npm run db:push      # Pushes schema using drizzle.config.ts
npm run db:studio    # Launches visual Drizzle Studio database browser

Verify live DB connectivity anytime from /dashboard/settings → Test Connection Now.

4. Running Background Worker & Production Builds

npm install
npm run typecheck    # Validates TypeScript across all 6 workspaces
npm run build --workspace=apps/web
npm run dev:web      # Local web server on http://localhost:3000
npm run dev:worker   # Background audit job worker (SKIP LOCKED)

5. Security & Compliance Controls

  • SSRF Defense Shield: validateUrlForSSRF blocks loopback, RFC 1918 private subnets, cloud metadata IPs (169.254.169.254), and non-HTTP ports before any audit fetch.
  • CSV Formula Defense: sanitizeCellValue neutralizes leading =, +, -, @ characters during import and export.
  • DPDPA 2023 & Suppression: Suppressed or deleted leads are excluded from outreach and search pipelines.
